## 검사 결과와 범위

원본 설계에는 사건 순서, 일부 행동축, 소품 상태가 이미 명시되어 있었다.
본 편집 검토에서 직접 모순으로 확정한 연결부는 없었다. 주된 보완 대상은 세계 위치,
카메라가 유지할 행동축 한쪽, 서로 마주 보는 시선, 팔·볼의 해부학적 좌우,
잡기→손 놓기→주먹질, 볼 만지기→손 내리기→보행 등 중간 상태다.
**정보 부족을 실제 단절 오류로 세지 않았다.** 이 검토는 독립 평가나 자동 정량 점수가 아니다.
기존 이미지 78장의 연결부를 모두 시각 판독한 검사도 아니다.

## 새 이미지에 추가한 것

같은 장면의 N/S/S−전이/S−길이에 공통으로 다음을 적용했다.

1. 인물 위치·진행 방향·행동축 한쪽과 소품 소유 상태를 명시했다.
2. 각 컷에 앞뒤 대표 순간을 텍스트 문맥으로 주고 현재 순간만 그리도록 했다.
3. 같은 인물 참조를 유지하고, 소품이 없는 깨끗한 공통 배경 2장을 새로 만들었다.
   기존 동굴 참조의 마석·방패와 산길 참조의 배낭 도해가 본 장면에 섞이지 않게 하기 위함이다.
4. 현재 컷의 접촉·부상·소멸·배낭·시선 상태를 별도로 지정했다.

기존 컷 수·순서·크기·시간·행동 원문·대사를 유지했다. 바바리안 S−전이의 목표 초과 101초도
그대로 보존했다. 원래 없던 좌우·정확한 자세 등은 **제작자가 사후 추가한 선택**으로 기록했다.
이전 생성 이미지를 다음 이미지에 연쇄 참조하지는 않았다. 공통 참조와 앞뒤 텍스트 상태로
연결을 유도한 방식이며, 이것만으로 시각적 연속성이 보장된다고 주장하지 않는다.
